1. 一个键叫出来

Option + Cmd + A：唤出 / 收起。别处点一下它就自动收走，不留窗口在桌面上。

2. 快捷键

记这 8 个就够了，全部可在 设置 → 快捷键 改：

快捷键 干什么
Option + Cmd + A 显示 / 隐藏（全局，应用在后台也生效）
Cmd + N 新建笔记
Cmd + F 搜标题和正文
Cmd + [ / Cmd + ] 上一条 / 下一条笔记（触摸板双指左右滑动同效）
Cmd + Shift + P 置顶 / 取消置顶
Cmd + Shift + D 钉到桌面 / 收回
Cmd + Backspace 删除（进回收站，能捞回来）
Esc 关搜索、从设置返回

顺手记两个不是快捷键的：行首输 / 出命令菜单，[[ 插笔记链接。

3. 收藏

  • 左边文件列表里右键笔记 → 收藏；
  • 收藏的笔记集中在侧栏顶部「收藏笔记」分组，随点随开；
  • 鼠标贴到屏幕边缘的白条上，会滑出收藏面板（快捷键默认没设，想用去设置里绑一个）。

4. 置顶（Pin）

  • Cmd + Shift + P 或标题栏那个图钉：置顶后窗口不再失焦自动收起，适合边查边写；
  • 取消置顶后是「继续显示」还是「直接隐藏」，在 设置 → 窗口 里选；
  • 想让笔记常驻桌面当便签：Cmd + Shift + D 钉成桌面卡片，能在桌面上勾待办。

5. AI

先配一次：设置 → AI 设置，填 API URL（默认 DeepSeek，OpenAI 格式都兼容）、API Key、模型。

怎么用

  1. 选中文字再唤 AI，只改这一段；不选就处理整篇。
  2. 右键 → 挑一个助手（自带「AI 优化」等模板，也能自己加）。
  3. 结果先给你看，再决定：插入原文之后 / 替换选中 / 替换全文 / 丢掉。
  4. 已经写进去的，Cmd + Z 能撤。

进阶两句

  • 自定义助手：设置 → AI 设置 → 添加助手，写名称 + 提示词，需要查资料就勾联网（要百度 AppBuilder Key）。
  • 空行输 /ip，直接插入本机地址和出口 IP 归属地。
